# 3D KHUJAND — Сервис 3D-печати и онлайн-расчёта

Интерактивный сайт для студии 3D-печати в Худжанде (Таджикистан) в стиле **Bambu Lab** и **JLC3DP**.
Позволяет клиенту прямо в браузере загрузить 3D-модель (STL, 3MF, OBJ), покрутить её на виртуальном столе принтера, выбрать пластик/цвет, моментально узнать вес, время и цену, и отправить заказ прямо в Telegram мастеру.

---

## Возможности сайта

1. **3D-стол (Three.js / WebGL):**
   - Виртуальный стол 256 × 256 × 256 мм (габариты Bambu Lab A1 / P1S / X1C) с миллиметровой сеткой.
   - Вращение, приближение, мягкие тени и проверка «помещается ли на стол».
   - Вращение модели на 90° вокруг осей X, Y, Z для поиска оптимальной ориентации.
   - Переключение единиц (мм, см, дюймы) и масштаба (5% – 1000%).

2. **Клиентский геометрический анализ (100% бесплатно и без сервера):**
   - Файл не отправляется на сервер для расчёта — всё считается прямо в браузере через ориентированные тетраэдры.
   - Точные размеры ($X \times Y \times Z$ мм), объём сетки (см³), площадь поверхности.

3. **Калькулятор стоимости (в сомони):**
   - 4 материала: **PLA** (базовый), **PETG** (прочный), **TPU** (гибкий), **Silk PLA** (шёлковый блеск).
   - Интерактивные палитры цветов под каждый пластик (графит, белый, оранжевый, синий, золото, серебро).
   - Настройка качества слоёв (0.12 мм, 0.20 мм, 0.28 мм) и процента заполнения (10% – 100%).
   - Учёт себестоимости пластика, амортизации оборудования и базовой стоимости запуска.

4. **Оформление заказа:**
   - Модальное окно с детальной сводкой параметров.
   - Поддержка отправки через Cloudflare Pages Function в Telegram-бота.
   - **Умный Fallback:** если бэкенд ещё не настроен, заявка автоматически копируется в буфер обмена и открывается диалог в Telegram с мастером.

5. **Ветка «Нет модели, есть фото»:**
   - Форма загрузки до 5 фотографий сломанной детали или эскиза рядом с линейкой.

## Запуск и разработка

```bash
# Установка зависимостей (уже выполнены в проекте)
npm install

# Запуск локального сервера разработки
npm run dev

# Запуск тестов геометрии и формул расчёта
npm test

# Сборка готового продакшн-дистрибутива (папка dist)
npm run build
```

## Бесплатный деплой (0 сомони навсегда)

### Вариант 1: Cloudflare Pages (Рекомендуется)
1. Загрузите проект в репозиторий GitHub.
2. В панели [Cloudflare Dashboard](https://dash.cloudflare.com) перейдите в **Workers & Pages** -> **Create application** -> **Pages** -> **Connect to Git**.
3. Настройки сборки:
   - **Framework preset:** `Vite`
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
4. Для автоматической отправки заявок прямо в Telegram добавьте 2 переменные окружения в настройках Cloudflare Pages:
   - `TELEGRAM_BOT_TOKEN`: токен вашего бота от `@BotFather`
   - `TELEGRAM_CHAT_ID`: ID вашего чата или канала для заказов (можно узнать через `@userinfobot`)
5. Нажмите **Save and Deploy**. Готово! Сайт доступен по адресу вида `3d-khujand.pages.dev` с бесплатным SSL.

### Вариант 2: Vercel
1. Зайдите на [vercel.com](https://vercel.com) и импортируйте репозиторий.
2. Vercel автоматически определит Vite и соберёт сайт в 1 клик.
